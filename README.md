# Hand Controlled Particle Cluster

A real-time AR experience controlled by hand gestures. Built with Three.js and MediaPipe.

## 🔗 Live Demo
**[Launch Experience](https://supriyosen.github.io/gesture_shape_control/)**

## Features
- **AR Experience**: 3D Particles overlay on your webcam feed.
- **Shape Morphing**: Open your hand to switch shapes (Sphere, Cube, Torus, Heart, etc.).
- **Scale Control**: Pinch (Thumb + Index) to scale the object.
- **Transparent Visuals**: Beautiful neon particles with transparency.

## How to Run Locally
1. Clone the repo:
   ```bash
   git clone https://github.com/supriyosen/gesture_shape_control.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run dev server:
   ```bash
   npm run dev
   ```
